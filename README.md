### AutoLogAnalyzer — ECU Log Parser & 3D Calibration Map Visualizer

Десктопное Windows-приложение на C++ и Qt 6 (QML) для высокопроизводительного парсинга CSV/LOG файлов систем управления двигателем (ЭБУ) и интерактивного построения 3D-карт калибровок в реальном времени по техническому заданию проекта turboquattro. 

Программа решает ключевую инженерную задачу чип-тюнинга: перевод линейных потоковых логов параметров двигателя во времени в структурированные трехмерные матрицы калибровочных поверхностей (например, RPM × THR → УОЗ). 

### 🚀 Ключевые возможности & Реализованный функционал

* **Высокопроизводительный C++ Парсер (LogParser):** 

  * Потоковое чтение и обработка больших массивов данных (протестировано на логах объемом более 13 500 строк).
  * Алгоритм автоматического определения разделителей шапки данных (запятая/точка с запятой).
  * Минимизация аллокаций памяти в куче за счет оптимизированного прохода по константным ссылкам контейнеров Qt (qAsConst).
* **Математическое квантование и интерполяция (Hit Count & Smoothing):** 

  * Преобразование временных рядов лога в жесткую таблицу узлов фиксированного формата 16×16.
  * Расчет значений ячеек по методу среднего арифметического всех физических попаданий в квант для обеспечения достоверности данных.
  * Двухпроходный алгоритм линейной интерполяции пропущенных зон по ближайшим соседям — устраняет провалы графика в ноль в режимах, где автомобиль не двигался («эффект парения рельефа над поверхностью»).
* **Современный декларативный UI на QML (Qt Quick):** 

  * Полная интеграция C++ бизнес-логики с графическим слоем через механизмы Q_PROPERTY и сигналы обратной связи.
  * Быстрое и отзывчивое переключение до 10 одновременно загрученных логов с автоматической синхронизацией выпадающих списков осей.
  * Полностью динамическое контекстное меню выбора целевого параметра Z по правому клику мыши, реализованное через производительную связку Instantiator и TapHandler в Qt 6.
* **Интерактивная 3D-визуализация (Qt Graphs 3D):** 

  * Плавный рендеринг объемной поверхности Surface3D с аппаратным форсированием API OpenGL для стабильной работы в виртуальных машинах (поддержка старых графических чипов вроде Intel HD Graphics 2000).
  * Плавная градиентная интерполяция цветов ячеек (синий — минимальные значения, красный — пиковые зоны).
  * Динамическое автовыравнивание линий сетки на стенках графика по реальным экстремумам матрицы.
  * Интерактивный трехмерный маркер замера параметров с автоматическим расчетом и синхронизацией осей.
* **Встроенный математический калькулятор:** 

  * Безопасное вычисление произвольных формул модификации ячеек в реальном времени с использованием изолированного движка QJSEngine на стороне C++ без динамической компиляции кода в QML.

### 🛠 Стек технологий & Окружение

* **ОС:** Windows 10 (разработка велась в изолированной среде VM)
* **Язык программирования:** C++20 (стандарт ISO)
* **Фреймворк:** Qt 6.10.3 (модули Core, Gui, Qml, Quick, Graphs)
* **Инструментарий сборки:** CMake 3.16+, Qt Creator IDE
* **Компилятор инструментария:** MinGW 13.10.0 64-bit

### 📁 Структура исходного кода проекта

* **CMakeLists.txt** — Конфигурационный файл сборки проекта и линковки модулей Qt 6
* **main.cpp** — Точка входа приложения, настройка RHI OpenGL графического бэкенда
* **logparser.h** — Объявление C++ класса парсера, структур данных и Q_PROPERTY
* **logparser.cpp** — Реализация парсинга логов, калькулятора, квантования и интерполяции
* **Main.qml** — Декларативная верстка интерфейса, логика маркера и 3D сцены
* **test_log.csv** — Тестовый файл лога чип-тюнинга для верификации рельефа

### ⚙️ Сборка и запуск

1. Убедитесь, что в вашей установке Qt добавлены библиотеки Qt Graphs и Qt Shader Tools.
2. Откройте файл CMakeLists.txt в среде Qt Creator.
3. Выберите комплект сборки (Kit) MinGW 13.10.0 64-bit.
4. Очистите кэш CMake и запустите конфигурирование проекта.
5. Выполните сборку (Ctrl + B) и запустите приложение (Ctrl + R).
